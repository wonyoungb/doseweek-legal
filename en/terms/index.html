4. Optional ad-free pass

In the free version you can choose to watch one rewarded ad and then use DoseWeek without ads for 24 hours. The condition is shown before the ad starts. The pass is granted only when the ad reports that the reward was earned; closing the ad early grants nothing. The pass is optional, is not a purchase, has no cash value and cannot be transferred. Declining it changes no Free feature. You can earn at most two rewards in any rolling 24 hours, and remaining ad-free time never exceeds 48 hours. While a pass is active, another rewarded ad is offered only when 24 hours or less remain. The pass pauses if the device clock is set back more than five minutes from the latest time the app has seen. While the pass is active, automatic ads and Plus subscription offers are hidden.

6. Your records

While Plus is active, you can separately consent to turn on automatic server backup and sync. App records are end-to-end encrypted on the device; the server cannot read the backed-up contents. Free users can still manually export and import files and use the in-app backup reminder.

DoseWeek does not use iCloud or CloudKit to back up app data. A backup file you manually export to a cloud location you choose is a separate path governed by that provider.

Android OS Google Drive Auto Backup includes DoseWeek app data only while Plus is verified and active; it then backs up the database, keys and records together as one complete set. If Plus is not active or cannot be verified, for example offline or when the store check fails, DoseWeek skips that backup run instead of sending an empty or partial backup, so the previous backup stays as it is. DoseWeek does not delete existing Drive backups, and you can still restore an existing backup. This backup is kept in your Google account under Google's rules, separately from DoseWeek server copies; you can manage or delete it in your Google account's backup settings. Users of 1.0.5 receive a one-time notice explaining this change and how to export a file. The notice does not block use of the app.

If you turn it on separately, DoseWeek encrypts all your records on the device (injection plans and their changes, dose records, meals, body measurements, supplies and import history) together with supported settings, for automatic backup and sync across both platforms. Your data key is stored only in a form locked by your recovery code, and the recovery code stays on your devices, so the operator cannot read your health records. The server handles account and provider identifiers, verified Plus state, ciphertext, versions and minimal access metadata, but receives neither readable health records nor your recovery code. A new device needs the recovery code; if it is lost, the developer cannot recover the encrypted data. An empty device may restore after code confirmation; a device with existing records requires a preview and merge confirmation. References use AES-256-GCM with a server-only key separate from the end-to-end health-record keys and are used only for store checks. Account deletion erases references; expired references are pruned after 30 days.
