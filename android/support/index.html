Android용 DoseWeek 도움말

DoseWeek는 DoseWeek 계정과 개발자 서버 없이 동작하므로 지원 담당자가 기기의 기록을 원격으로 보거나 복구할 수 없습니다.

!
지원 이메일에 건강 정보, 약물·투여 기록, 개인 메모, 백업 파일 또는 복구 코드를 포함하지 마세요.
기록은 어디에 저장되나요?

현재 일정, 투여·건너뜀 기록, 주사 부위, 메모, 재고 수량, 체중과 허리둘레는 해당 Android 기기의 앱 전용 저장소에 보관됩니다. 사용자가 만든 암호화 백업 사본만 사용자가 선택한 파일 위치에 별도로 저장될 수 있습니다. 선택 사항인 Google Drive 백업을 켜면 암호화된 사본이 사용자 본인의 Google Drive 앱 데이터 폴더에도 보관됩니다.

로그인이나 계정이 필요한가요?

DoseWeek 1.0.0에는 계정도 개발자 서버도 없으며, 앱을 사용하는 데 어느 것도 필요하지 않습니다. 선택 사항인 Google Drive 백업은 사용자 본인의 Google 계정을 사용하고, 설정에서 직접 연결하기 전까지 꺼져 있습니다. 어느 경우에도 개발자는 사용자의 기록을 볼 수 없습니다.

AI 또는 Health Connect를 사용하나요?

DoseWeek 1.0.0에는 여전히 생성형·온라인·온디바이스 AI가 없습니다. Health Connect는 이제 체중, 키, 체지방률, 제지방량을 가져오는 선택 사항 읽기 전용 연동으로, 읽기 권한만 요청하고 쓰기나 삭제 권한은 요청하지 않으며, 사용자가 권한을 허용하기 전까지 아무것도 가져오지 않습니다. 모든 투여 기록은 지금도 사용자가 직접 입력하고 확인합니다.

알림, 리마인더 또는 위젯을 제공하나요?

선택형 리마인더와 홈 화면 위젯을 제공합니다. DoseWeek 1.0.0은 다음 투여, 놓친 투여의 후속 안내, 재고 부족에 대한 로컬 리마인더를 기기 안에서 예약할 수 있습니다. 리마인더는 사용자가 켜고 알림 권한을 허용하기 전까지 꺼져 있습니다. 기본 문구는 치료 내용을 드러내지 않으며, 약 이름은 사용자가 켠 경우에만 표시되고 용량은 표시되지 않습니다. 리마인더를 눌러도 앱이 열리기만 하므로 알림에서 어떤 기록도 남지 않습니다. 워치 앱은 없습니다.

기록을 백업하거나 복원할 수 있나요?

예. 설정에서 Android 시스템 파일 선택기를 사용해 모든 앱 데이터를 AES-256-GCM으로 암호화된 파일에 수동 저장하고 해당 파일을 선택해 복원할 수 있습니다. 별도의 고엔트로피 복구 코드가 필요합니다. 앱 데이터는 Android 시스템 백업과 기기 간 전송에서 계속 제외됩니다.

이 내보내기에는 DoseWeek 계정이나 광범위한 저장소 권한이 필요하지 않으며, 내보내기 자체는 네트워크를 사용하지 않습니다. 외부 또는 클라우드 문서 제공자를 선택하면 해당 제공자의 정책과 약관이 적용됩니다. 선택 사항인 Google Drive 백업은 사용자가 직접 켜는 별개의 경로로, 업로드 전에 기기에서 암호화한 뒤 사용자 본인의 Drive 앱 데이터 폴더에 올립니다. 어느 경우에도 개발자는 파일이나 복구 코드를 받지 않으며 잃어버린 코드를 재설정하거나 파일을 복호화할 수 없습니다. 복원은 파일 전체를 검증한 뒤에만 현재 데이터를 하나의 원자적 로컬 트랜잭션으로 교체합니다.

모든 기록을 삭제하려면 어떻게 하나요?

DoseWeek 설정의 모든 데이터 삭제를 사용하세요. 앱을 제거해도 Android가 로컬 앱 데이터를 삭제합니다. 앱 밖에 저장한 백업 파일은 자동으로 삭제되지 않으므로 Android 파일 앱이나 해당 문서 제공자에서 별도로 삭제하세요. 사용자 본인의 Google Drive에 올린 백업도 앱을 제거한다고 지워지지 않습니다. 앱 안의 백업 목록에서 지우거나, Google 계정에서 이 앱의 데이터를 삭제하세요.

지원 담당자가 삭제된 기록이나 복구 코드를 복구할 수 있나요?

아니요. 개발자는 기기의 기록이나 복구 코드에 접근할 수 없고 서버 사본도 보관하지 않습니다. 호환 백업 파일과 정확한 복구 코드가 모두 있으면 앱에서 직접 복원할 수 있지만, 지원 담당자는 잃어버린 파일·코드 또는 삭제된 기록을 대신 복구할 수 없습니다.

출시 전 안내: 날짜와 시각 선택

날짜나 시각을 누르면 시스템 선택기가 열립니다. 오래된 날짜는 월·연도를 바꾸고, 오전·오후가 표시되면 함께 선택하세요. 취소하면 기존 입력이 유지되고, 선택을 확정하면 입력 중인 값만 바뀝니다. 기록의 저장 버튼을 눌러야 반영됩니다. 연필 버튼으로 직접 입력할 수도 있습니다. 날짜는 YYYY-MM-DD 또는 YYYYMMDD, 시각은 24시간 HH:mm 또는 HHmm 형식입니다.

기록 화면에서 과거 날짜를 고르고 과거 투약을 추가하세요. 약품·용량·단위·실제 투약 시각을 확인한 뒤 저장합니다. 계획 없이 기록만 관리할 수도 있습니다. 계획 없이 기록한 항목은 일정·재고를 바꾸지 않습니다. 계획에 연결된 기록은 표시되는 재고 차감 여부를 확인하세요. 암호화 백업 복원은 데이터를 교체하는 별도 기능입니다. 과거 기록의 재고 차감은 기본으로 꺼져 있으니 표시된 선택을 확인하세요. 연결된 계획의 최신 투약이 바뀌면 향후 미해결 일정이 조정될 수 있습니다.

먼저 원래 기록한 앱과 헬스 커넥트에 측정값이 있는지 확인하세요. DoseWeek 신체 화면에서 지표와 기간을 확인합니다. 설정에서 헬스 커넥트를 열고 지금 가져오기를 누르세요. 결과가 없으면 읽기 권한과 이전 기록 권한, 원래 앱의 동기화 상태를 각각 확인하세요. 측정 날짜는 가져온 시각이 아니라 실제 측정 시각입니다.

식사와 영양을 기록할 수 있나요?

신체 탭의 '식사' 구역에서 직접 입력합니다. 음식 이름과 아는 총량(열량, 단백질, 탄수화물, 지방)을 넣고 모르는 값은 비워 두면 '모름'으로 남습니다. 한 끼에 최대 100개 항목, 즐겨찾기 1,000개까지 저장됩니다. 이 버전에는 음식 검색 데이터베이스가 없고, 기록은 기기에만 저장되며 암호화 백업에 포함됩니다. 식사 기록은 영양 상담이나 처방이 아닙니다.

일정 편집에서 '직접 고른 날짜' 방식을 선택하면 달력에서 예정일을 여러 개 고를 수 있습니다. 고른 날짜는 미리보기로 확인되고, 확인된 의약품 정보의 최소 간격보다 가까운 미래 날짜는 저장이 막힙니다. 이미 지난 실제 기록은 막지 않습니다. 마지막 날짜가 지나도 계획은 유지되며 날짜를 추가하라는 안내가 표시됩니다.

설정에서 직접 켜기 전까지 꺼져 있고, 켤 때 캘린더 권한을 따로 요청합니다. 켜면 선택한 캘린더 한 개에 앞으로 84일 이내의 주사 예정일을 최대 24개까지 30분짜리 일정으로 기록합니다. 제목은 기본값 '개인 알림'이며 직접 선택할 때만 '주사 예정일'이 되고, 약 이름·용량·부위·메모·알림은 기록하지 않습니다. 앱은 자신이 만든 일정만 수정·삭제하며, 사용자가 직접 바꾼 일정은 더 이상 건드리지 않습니다. 연동을 끄면 앞으로의 일정을 삭제할 수 있고, 앱을 삭제해도 캘린더에 남은 일정은 그대로 남습니다.

Yes. In Settings, use Android's system file picker to manually save all app data in an AES-256-GCM encrypted file, and select that file to restore. A separate high-entropy recovery code is required. App data remains excluded from Android system backup and device-to-device transfer.

This export needs no DoseWeek account and no broad storage permission, and the export itself uses no network access. Restore completely validates the file before replacing current data in one atomic local transaction.

Use Delete all data in DoseWeek Settings. Uninstalling the app also causes Android to delete local app data. Backup files saved outside the app are not deleted automatically; delete them separately through Android's file app or their document provider. Backups you uploaded to your own Google Drive are not removed by uninstalling either: delete them from the backup list inside the app, or by removing the app's data from your Google account.

No. The developer cannot access records or recovery codes on your device and keeps no server copy. If you have both a compatible backup file and its correct recovery code, you can restore it in the app; support cannot recover a lost file or code or restore deleted records for you.

Ajuda do DoseWeek para Android

O DoseWeek funciona sem conta DoseWeek nem servidor do desenvolvedor. Por isso, o suporte não consegue visualizar nem recuperar remotamente os registros do dispositivo.

!
Não inclua informações de saúde, registros de medicamentos ou administrações, observações pessoais, arquivos de backup ou códigos de recuperação em um e-mail de suporte.
Onde meus registros são armazenados?

Agendas, administrações realizadas ou ignoradas, locais de injeção, observações, estoque, peso e circunferência da cintura permanecem no armazenamento privado do aplicativo nesse dispositivo. Somente um backup criptografado criado pelo usuário pode ser armazenado separadamente. Se você ativar o backup opcional no Google Drive, uma cópia criptografada também fica na sua própria pasta de dados de aplicativo do Google Drive.

Preciso fazer login ou criar uma conta?

O DoseWeek 1.0.0 não tem conta própria nem servidor do desenvolvedor, e você não precisa de nenhum dos dois para usar o aplicativo. O backup opcional no Google Drive usa a sua própria Conta do Google e fica desativado até você conectá-lo nas configurações. Em nenhum dos casos o desenvolvedor consegue visualizar os seus registros.

O DoseWeek usa IA ou Health Connect?

O DoseWeek 1.0.0 continua sem IA generativa, online ou no dispositivo. O Health Connect agora é uma importação opcional e somente de leitura de peso, altura, percentual de gordura corporal e massa magra: o aplicativo pede apenas permissões de leitura, nunca de gravação ou exclusão, e não importa nada até você conceder essa permissão. Cada administração continua sendo inserida e confirmada manualmente.

O aplicativo oferece notificações, lembretes ou widgets?

Estão disponíveis lembretes opcionais e um widget para a tela inicial. O DoseWeek 1.0.0 pode agendar no dispositivo lembretes locais para a próxima administração, um acompanhamento após uma administração perdida e estoque baixo. Eles ficam desativados até você ativá-los e conceder a permissão de notificação. Por padrão, o texto do lembrete não revela nada sobre o seu tratamento; o nome do medicamento só aparece se você ativar, e as doses nunca aparecem. Tocar em um lembrete apenas abre o aplicativo, então nada é registrado a partir de uma notificação. Não há aplicativos para relógio.

Posso fazer backup ou restaurar meus registros?

Sim. Nas configurações, use o seletor de arquivos Android para salvar manualmente todos os dados em um arquivo criptografado com AES-256-GCM e selecione-o para restaurar. É necessário um código de recuperação separado e de alta entropia. Os dados permanecem excluídos do backup e da transferência do sistema Android.

Esta exportação não precisa de conta DoseWeek nem de amplo acesso ao armazenamento e, por si só, não usa rede. Se escolher um provedor externo ou em nuvem, os termos dele serão aplicados. O backup opcional no Google Drive é um caminho separado que você mesmo ativa: ele criptografa no dispositivo antes de enviar para a sua própria pasta de dados de aplicativo do Drive. Nos dois casos, o desenvolvedor não recebe o arquivo nem o código e não pode redefinir um código perdido nem descriptografar o arquivo. A restauração valida tudo antes da substituição atômica em uma transação local.

Como excluo todos os registros?

Use Excluir todos os dados nas configurações. A desinstalação também exclui os dados locais. Os backups externos permanecem e precisam ser removidos separadamente. Os backups enviados para o seu próprio Google Drive também não são removidos pela desinstalação: exclua-os na lista de backups dentro do aplicativo ou removendo os dados do aplicativo da sua Conta do Google.
