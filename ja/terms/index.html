利用規約

iPhone、iPad、Android版DoseWeekの利用規約です。広告付きの無料版、任意のPlusサブスクリプション、App StoreとGoogle Playでの支払い、記録アプリとしての限界について説明します。

1. サービス

本規約は、iPhone、iPad、Android向けのDoseWeekアプリと、このヘルプウェブサイトに適用されます。DoseWeekは、注射のスケジュール、投与、関連するメモを記録するための個人用の記録ツールで、大韓民国を拠点とする個人開発者Wonyoung Choiが運営しています。DoseWeekを利用することで、本規約に同意したものとみなされます。情報の取り扱いについては、ご利用のプラットフォームのプライバシーポリシーで説明しています。

2. 無料版とPlus

DoseWeekは無料でダウンロードでき、無料版では無料版のユーザーに広告が表示されます。Plusは月額または年額で自動更新される任意のサブスクリプションで、広告を非表示にし、期間サマリーと比較、受診レポートエディター、「今日」画面のレイアウトプリセット、食事テンプレートを追加します。

Plusの導入前からDoseWeekにあった機能は引き続き無料で、Plusに移されることはありません。Plusが終了しても、記録、テンプレート、保存した設定は保持されます。すべての方に同じ無料版のポリシーが適用され、以前の有料版のDoseWeekを購入していてもPlusは含まれません。

価格と請求期間は、購入前にアプリとストアに表示されます。

3. 支払い、更新、解約

Plusは、iPhoneとiPadではApp Storeが、AndroidではGoogle Playが、サインインしているアカウントで販売・請求します。サブスクリプションは、解約するまで各期間の終了時に自動的に更新されます。解約はストアのサブスクリプション設定で行え、この設定はDoseWeekの「設定」から開けます。解約した後も、支払い済みの期間が終わるまでPlusは有効のままです。アプリやそのデータを削除しても、サブスクリプションは解約されません。

返金は、AppleまたはGoogleがそれぞれの返金ポリシーに基づいて処理します。Plusの価格が変更される場合は、ストアが自社のルールに従って事前にお知らせし、そのルールで求められる場合は、新しい価格が適用される前に同意を求めます。あるストアで購入したPlusは、そのプラットフォームのDoseWeekでのみ使えます。プラットフォーム間でPlusを共有するためのDoseWeekアカウントはありません。

iPhoneとiPadの場合（App Store）

購入を確定すると、Appleアカウントに請求されます。現在の期間が終わる24時間以上前に自動更新をオフにしない限り、サブスクリプションは自動的に更新され、現在の期間が終わる前の24時間以内に更新料金がアカウントに請求されます。サブスクリプションの管理やキャンセルは、Appleアカウントのサブスクリプション設定で行えます。月額と年額の間の変更は、次回の更新日から適用されます。返金はAppleに申請してください。

iOSアプリには、Appleの標準の使用許諾契約（Licensed Application End User License Agreement、EULA）も適用されます。
https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

Androidの場合（Google Play）

購入を確定すると、Google Playアカウントのお支払い方法に請求されます。サブスクリプションは、Google Playの「お支払いと定期購入 > 定期購入」で解約するまで自動的に更新されます。次回の請求を避けるには、更新日より前に解約してください。月額から年額への変更はすぐに適用され、月額プランの未使用期間はGoogle Playが年額プランに充当します。年額から月額への変更は次回の更新日から適用されます。返金はGoogle Playの返金ポリシーに従い、購入にはGoogle Playの利用規約も適用されます。

4. 任意の広告なしパス

無料版では、希望すればリワード広告を1本視聴した後、30分間DoseWeekを広告なしで使えます。条件は広告が始まる前に表示されます。このパスは、広告が特典の獲得を報告した場合にのみ付与され、広告を途中で閉じると付与されません。このパスの利用は任意で、購入ではなく、換金価値はなく、譲渡もできません。断っても無料版の機能は何も変わりません。

5. 医療に関する注意

DoseWeekは個人用の記録ツールであり、医学的助言、診断、治療を提供するものではありません。投与スケジュールや用量など、治療に関するすべての決定は、必ず医師または薬剤師にご相談ください。

本プログラムは医療機器ではありません。疾病の診断、治療、予防を目的としていません。

医療上の緊急事態の可能性がある場合は、直ちに現地の緊急通報先に連絡してください。アプリサポートのメール回答を待たないでください。

6. ご自身の記録

記録はご自身の端末に保存され、ご自身のものです。DoseWeekにはアカウントがなく、開発者が健康記録を受け取ることはありません。端末、バックアップ、書き出したファイル、復旧コードは、ご自身で安全に管理してください。開発者は、失われた記録、ファイル、コードを復元できません。Plusを利用しても、記録の保存場所は変わりません。

7. 本規約の変更

本規約を変更する場合は、新しい施行日とともに変更後の規約をこのページに掲載します。価格の変更は、第3項で説明したストアのルールに従います。変更に同意しない場合は、いつでもDoseWeekの利用をやめ、ストアでPlusを解約できます。
